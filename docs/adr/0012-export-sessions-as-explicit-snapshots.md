# Export Sessions as explicit snapshots

`export` accepts `current`, `current-thread`, or one Session ID and requires one destination, with `-` selecting standard output. `current` exports only the top-level Session, never a combined family document. It captures the Session content available when the command runs rather than waiting for the Harness to finish. Markdown is the default format and includes provenance followed by the readable Transcript; `--format raw` is sufficient consent to preserve the potentially sensitive Harness file exactly. Existing destination files are rejected unless `--force` is supplied. This avoids silently creating or replacing files in a Project, keeps exports useful outside `agsearch`, and makes active-Session exports predictably finite. Batch selection, family bundles, and automatic end-of-Session hooks remain separate future work built on this command.
