## Agent skills

### Issue tracker

Issues live in GitHub Issues (`gh` CLI); `.scratch/ccsearch/` holds legacy pre-remote issues, read-only. See `docs/agents/issue-tracker.md`.

### Triage labels

Default canonical strings (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), applied as GitHub labels; `done` = close the issue. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
